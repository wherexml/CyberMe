# CyberMe · Today 流程 Mock

独立静态原型：连续主对话 + 有证据的灵感决策卡 + 关联任务，任务结果回到同一段对话。全部为**合成演示数据**（虚构项目「Atlas 3.2 发布评审」），不调用后端、模型或外部资源，不代表真实执行。

## 打开

直接用浏览器打开 `mock/cyberme-today-flow/index.html`（file:// 即可，无需服务）。产品窗口固定 1000×700，小屏按比例缩小。状态保存在 localStorage `cyberme-today-flow-v1`；预览条「重置」恢复初始示例。

深链：`#today`、`#card/c1`、`#tasks`、`#task/t1`、`#memory`。

## 演示路径

1. Today → 打开「回滚负责人」卡片 → 展开来源摘录。
2. 「带入对话」→ 输入框上方出现可移除的对象标签 → 输入追问并发送。
3. 回复中「创建核对任务」→ 任务页打开 → 用「演示：推进一步」推进；到「等你确认」时必须明确选择才继续。
4. 完成后查看结果；结果同时回到主对话。「回到对话」高亮来源消息并附上任务引用。
5. 预览条「模拟来源变化」：清单 v4→v5，卡片撤回旧判断、旧引用标为过期，任务结果标为基于旧版本，需重新核对。

## 失败与边界情况（实现前登记）

- 来源变化后，旧卡片、旧对象引用、进行中或已完成的任务都不能继续以旧证据呈现为当前结论；追问旧引用时明确拒答并给出更新入口。
- 「未找到记录」不得写成「未完成」或「确实没有」；证据缺口卡保持待确认状态。
- 任务在「等你确认」时不能被推进按钮跳过；暂缓保持等待，不伪装完成。
- 任务基于旧来源时禁止继续推进，只能按新版本重新核对。
- 无对象引用的“这个”类追问不猜测，提示从卡片带入。
- 主对话与每个任务的输入草稿在切换页面、刷新后保留；发送后才清空。移除引用不清空草稿。
- 重复点击「创建核对任务」只打开已有任务，不重复创建。
- localStorage 不可用时仍可在内存中演示，不报错。
- 所有动作只改变本地示例状态；不发送消息、不调用工具、不付费。
