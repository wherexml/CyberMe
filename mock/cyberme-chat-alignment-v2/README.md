# CyberMe 对话对齐 Mock v2

本轮仅独立 Mock，按用户 2026-10-25 截图调整。保留上一版及正式客户端源码。

## 实现前失败面

- 消息区与输入框使用不同宽度/滚动条占位，左右边缘偏移。
- 消息操作占位使用户气泡右边缘缩进；长助手气泡未用满共享宽度。
- 压缩输入框后文字/图标偏心、多行被截断、输入法回车误发送。
- 输入框遮挡最后一条消息，缩放后失去对齐。
- Mock 发送被误当真实AI/外发；附件被上传；示例混入真实业务信息。

## 设计

- 1000×700逻辑窗口；消息和输入框共用同一个父列，左右各28px；滚动条覆盖式且不占布局宽度。
- 助手左边缘与输入框左边缘重合，用户右边缘与输入框右边缘重合，长助手气泡可填满共享列。
- 单行输入框46px，左右10px、上下8px，28px图标控件；多行按内容增长至132px。
- 气泡正文左右12px，列表/段落紧凑。Radix Gray/Blue，0.5px边框。
- 输入、Enter发送、Shift+Enter换行、附件名称/移除仅在内存中演示；无网络、模型、真实外发或上传。
- 外部“对齐参考线”只用于设计核对，不属于产品UI；可用edit-mode消息开启密度与宽度Tweaks。

## 运行

`node scripts/cyberme-chat-alignment-mock.mjs`

打开 http://127.0.0.1:46424/ 。缩小浏览器时按完整桌面窗口等比缩放。

## 浏览器复验

Chrome实测：助手左边缘与输入框左边缘差0px，用户右边缘与输入框右边缘差0px，单行46px；三行输入自动增至89px，Enter发送本地用户气泡后恢复46px并清空输入；正文换行保留，无横向溢出。对齐参考线开关正常，控制台无错误。

重复步骤：打开页面→检查左右参考线→输入三行→按Enter→检查最后气泡及输入框恢复→刷新回到初始示例。截图和尺寸证据位于本机 `output/chat-alignment-mock-v2-20261025/`。仅静态Mock验证，不涉及正式客户端构建、安装或生产服务。
