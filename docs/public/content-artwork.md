# 内容图标与本机更新

## 实现前失败清单

- 旧 OpsTwins 原创图标没有进入 V6 打包，预览可见但安装版缺图。
- 记忆资料夹继续混用实心文件夹、线框人物和其他风格；简报忽略已有 `iconKey`。
- 不合法 key 或任意 URL 进入图标地址；图片失败时卡片失去布局或不能操作。
- 缺少明确选择时随机选到不相关内容，刷新时更换图标。
- 窄窗和深色主题下图标尺寸、背景或渐变失真。
- 本机更新覆盖刚安装的新修复、打入并发变更、改写原人员 Wiki 或用户草稿。
- 新版未真正替换并重启、健康检查失败却声称完成。
- 原生代理或桌面网关任一层白名单漏掉新增人物只读接口，HTTP 验收通过但安装版显示读取失败；需在安装版实际打开人物档案验收。

## 契约

复用旧版 `docs/design/assets/idea-icons/` 的 48 枚原创 SVG，与旧 OpsTwins 副本逐字节核对。记忆总览、资料夹及简报内容共用一个渲染组件；导航和操作控件继续使用既有字体图标。有效 `iconKey` 优先，其次按明确标题/目录词匹配，最后使用固定的语义后备图标；不改变业务状态、不回写历史记录、不调用模型补图。

图标通过 Vite 的本地静态导入进入 Web 和原生嵌入资源。使用独立图片隔离 SVG 渐变 ID，只接受目录白名单，不接受外部地址。图片失败回退既有线形图标，保留尺寸和交互。

本机候选以当前安装包为基线，保留未涉及的运行文件与数据；仅接入记忆资料库接口和本轮前端资源。更新沿用签名、备份、运行门控、重启和健康回执。浏览器图标验收与安装版实际效果分别记录。

原生代理和桌面网关仅为 `/api/memory-library/people` 增加精确 GET 白名单；不开放该命名空间的任意路径或写方法。
