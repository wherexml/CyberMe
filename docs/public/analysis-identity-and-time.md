# 分析身份、人物档案与证据时间

## 实现前失败面（2026-11-06）

1. 专用灵感任务不加载本人身份；正文中的本人姓名被当成第三方。
2. 聊天快照丢失发言人、方向、消息 ID、回复关系和逐条时间；本人交办变成本人待办。
3. 已有人员 Markdown 未进入分析；高管协作者、同级、直属员工的职责被混同。
4. 人物观察只存在于单次输出，没有带来源的持续记录；模型猜测关系或完成状态。
5. 整个会话的最新时间让几天前的引用获得新鲜度；同步/编辑时间冒充事件时间。
6. 不同时段、不同问题因同一会话被合并；已恢复故障因缺少复盘再次推送。
7. 重复正文匹配错发言人；姓名相同覆盖 isMine=false；没有时区的时间被猜测。
8. 身份、档案、消息或权限在生成期间变化，旧结果仍被采用。
9. 档案自动更新覆盖人工正文、生成重复记录、产生递归灵感；撤权后派生记录继续进入分析。
10. 历史提醒继续发送；修复改写普通聊天、现有任务或审批；验证误用真实私聊外发。
11. 安装版首轮发现：资料在首个检索前更新，`sources_changed` 被工具包装为普通错误；强制检索条件始终未满足，模型反复调用直至超时。须立即中止过期快照，不把重试循环算完成。

## 契约

- 本人身份显式进入分析；已验证方向优先于显示名。同名外部联系人不得被当作本人，身份冲突保留未知。
- 每条聊天证据携带消息 ID、发言人、方向和精确事件时间。本人交办、本人承诺、第三方请求、知悉和进展分开判断；交办执行责任保留给原负责人，不默认生成本人任务。
- 已有私有人员 Markdown 是角色背景，保留原文与复核日期；未知关系不猜测，高管身份不等于汇报关系。长期职责与短期事件分开存储。
- 历史资料可检索；主动推送必须有最近 24 小时内的具体新证据，不能用容器、同步或分析生成时间更新旧引用。未知时间保持安静。明确历史复盘仍可生成分析，但不主动推送。
- 同会话不等于同一事项；恢复消息与故障按明确引用/回复关系核对，缺复盘本身不构成重新打开故障的依据。
- 人物更新须逐字证据及精确人物关联；保存本地 Markdown 追踪与历史，不覆写既有人工档案，不自动外发或创建业务任务。
- 原始人员资料、私有配置与验收输出不入 Git。HTTP/SQLite/受控模型、真实模型与安装版分别记录。

## 人物与责任

- 通过既有知识目录设置接入人员 Wiki。仅识别含 `TEMPLATE.md`、`## 基本信息` 的明确配置目录，最多扫描两层、100 个档案；跳过链接及非人员文档。相关档案最多16份、每份12000字，携带原复核日期和截断状态，不把旧名册等同于今天的组织核验。
- 关系读取原 Markdown 的“与 Steve 的关系”，角色读取“当前角色”。未注明的关系是待确认；不得把高管自动认作上级，也不得把全部员工当直属。
- `owner_request` 是别人请求本人处理；`owner_commitment` 是本人明确承诺；`delegation` 是本人交办他人；`information` 是无需本人行动的信息。聊天触发证据的真实方向与前三类矛盾时拒绝输出。后两类不生成本人灵感任务。
- 人物增量独立于 `ideas`，允许“没有新建议但有新人物记录”。`personUpdates` 逐条绑定档案和原文，不允许把甲的消息记到乙名下。只有提到该人或明确由该人发出的证据才能采用。
- 新观察保存在私有 SQLite 的 `memories.kind=person_tracking`，正文为可读 Markdown，记录事件时间、分类和来源。原人员 Wiki 继续是人工角色依据；不改写其正文。跟踪正文中自动区之前的人工补充保留，既有版本进入 `person_tracking_history`，同证据去重；删除的记录不自动复活。当前未新增 V6 人物档案页面，可通过既有记忆实体接口读取全文。
- 跟踪记录不作为新的灵感来源；再次使用观察时必须复核原来源仍可读、原消息/正文/方向/时间仍一致。来源窗口之外的旧观察只保留历史，不冒充已复核的当前事实。

## 时间与采用

- 消息时间仅接受 epoch 秒/毫秒或带时区的日期；格式不明确、未来时间均不能用于主动提醒。
- 每条聊天证据绑定 `messageId`；唯一逐字匹配可补绑定，重复正文无 ID 则拒绝。第一条证据是触发事实，其余是背景；生成和提醒均核对该条消息的真实时间。
- 最近24小时的新触发事实才生成当前建议和主动提醒，几天前材料仍可参与检索和人物历史记录。会话最后活动、同步、生成时间不能改变引用的新鲜度。当前接口不会将纯历史复盘保存为新的当前灵感。
- 既有聊天提醒若缺新版责任校验或触发事实已过时，不再展示/投递，原派生消息软删除可追溯；普通用户/助手消息、任务和发送账本不改写。不将建议过期声称为实际事项完成。
- 身份和人员文档指纹加入分析快照，生成期间变化拒绝迟到结果。收件箱判断也加载相关档案与完整本人身份；原冷却、回复方向、权限和发送批准继续有效。
