# 连接资料、判断与草稿的新鲜度

## 修改前失败清单（2026-11-05）

- 附件原始资源键存在但下载失败；CLI 输出路径必须相对其工作目录，禁止 `..`，文件名不能是 `.`/`..`；返回路径、符号链接、空文件不可进入索引。删除的消息不再尝试下载。权限不足和已失效资源保留部分失败。
- 实时飞书查询的无时区展示时间丢失精确排序；只按精确消息 ID 和会话匹配原始时间，不能猜时区；父消息、线程回复和跨群结果同样处理。缺失、错配、超时必须显式 partial。
- 微信超过 1,000 会话或单轮 100 个变更会话时，下一轮重复第一页而饿死后续；重启需续读，账号/连接/设置变化需失效，游标重复不能循环。预算在页内耗尽不能跳过未处理项；续读期间也需查看首页的新消息。
- 本地模型将本人给对方的任务、对方确认误判成对本人的请求；重复长规则挤占会话证据。新的实质问题仍需被识别。
- 显式“重新分析”复用旧成功结果；普通刷新、重启仍应复用同版本。冷却、权限变化、在途版本核验不能被强制重算绕过。
- 来源变化使自动草稿过期，但队列因已有正文不再准备新稿；人工稿、手动请求稿、候选稿及未知生成不得覆盖。历史自动稿保留；无需回复时不再起草。新稿采用前再次核对消息和上下文。
- 模型收到毫秒数字时间后自行换算出错；提供标准 ISO 时间，未知时间仍保留未知。

## 验收边界

先扩展公开合成 HTTP/SQLite/CLI E2E，再修改实现。真实验收使用本机安装版、既有授权和精确来源，只读取、分析和准备草稿，不发送。产物只保存计数、状态、时间、哈希和判定，不保存私人正文或凭证。

## 实现契约

- 飞书附件在该资源的私有缓存目录内运行 CLI，仅传安全文件名；返回文件须非空且 realpath 落在该目录。撤回/删除消息不产生“缺少附件引用”误报。上游 14005 记为 `attachment_resource_deleted`，24 小时内复用失败事实，仍报告 partial，不伪装已下载。
- 实时查询在现有 55 秒预算内补读最多 50 个缺时间消息的原始记录，精确核对 message_id/chat_id；失败、缺失或超限保留 gap。判断、草稿及显式 Chat 上下文统一传递 ISO 时间；无时区字符串不猜测。
- 微信每轮仍限制 60 秒、1,000 个会话元数据及 100 个变更会话。未处理完的页保存游标，下一轮/重启续读；连接版本、来源账号、配置版本变化使游标失效。续读时先检查首页，最多读取 20 个首页变更，给后续页保留预算。`scanComplete` 仅指本次游标遍历结束，`windowLimited` 继续表达消息窗口，不能称全历史。
- `force:true` 只跳过成功判断缓存，不能跳过冷却、读取权限或在途版本核验；普通请求和重启保持同版本去重。
- 草稿记录 `draftSourceVersion`；来源/上下文变化标记 stale 并撤销旧批准。自动队列仅刷新符合当前回复判断的过期自动稿。人工稿、手动请求稿、候选稿、失败/未知请求不自动覆盖。被新生成结果替换的旧稿写入独立历史记录，发送回执不变；用户明确保存当前稿才确认其新版本。

## 重复执行

- `node --import tsx scripts/feishu-attachment-freshness-http-e2e.mjs`
- `node scripts/feishu-context-http-e2e.mjs`
- `node scripts/wechat-background-sync-http-e2e.mjs`
- `node --import tsx scripts/inbox-omlx-cooldown-http-e2e.mjs`

以上均是公开样本的生产 HTTP、真实 SQLite 与受控 CLI/模型端到端验证。结果写 `output/`，真实安装验收单独记录，不能互相替代。

真实复验增量：本地判断规则只传一次，明确本人/对方方向；已核实的私聊聚焦最近本人发言及其后的来信，完整来源仍用于版本校验。策略版本升级使旧判断失效；处理结论变更或确认无需回复时，旧稿标记过期并撤销批准。群聊仍保留精确提及与回复关系，不套用私聊截断。真实模型公开正反例入口：`node --import tsx scripts/inbox-reply-direction-live-e2e.mjs`。

本地模型返回的紧凑数字/布尔值、明确选项与无 `answers` 包装的完整字段可做等价归一化；未知枚举、缺字段、越界数值仍失败。模型没有报告置信度时不补造分数。比请求更早的本人消息不能作为回复证据；“无需动作”的确认不误标成“已回复”。飞书 CLI 的 HTTP 状态码和正文业务码分别解析，避免 HTTP 400 遮住资源删除码 14005。

安装验收额外发现：构建机的 Anthropic SDK 依赖树缺失公开运行文件，API 健康正常但首次 Chat 懒加载失败。先用实际失败请求回查确认没有外发，再按 lockfile 的版本与完整性恢复依赖。独立包构建须用包内 Node 实际加载模型运行依赖，不能以 TypeScript/Vite 构建通过代表运行依赖完整。
