# 窗口拖动与关闭

CyberMe 0.1.6 本机修复（2026-10-24）：

- 灵感、任务页标题及其上方留白支持移动原生窗口。
- 设置顶部38pt空白区支持移动所属原生窗口，标题栏中的关闭按钮仍正常工作。
- 「文件 → 关闭窗口」提供 Command+W：先关闭当前弹窗或设置，没有弹窗时走原生窗口关闭流程。
- 输入框、按钮、链接、可编辑内容和侧栏分隔条不触发窗口移动；释放指针后忽略迟到的定位结果。关闭弹窗遵守 cancel 事件。

窗口桥接仅作用于调用方。后台服务生命周期沿用既有行为，不因本次窗口修复改动业务执行或数据协议。

## 验证

隔离入口：`node --import tsx scripts/mygo-window-controls-service.mjs <生成资源目录>`，使用46780/46781及合成数据；`ego-browser nodejs < scripts/mygo-window-controls-browser-e2e.mjs`输出可重复的JSON结果。16项页面检查通过，原生桥接在浏览器中为模拟实现。

已安装0.1.6另行通过真实macOS验收：三处拖动均观察到系统窗口坐标变化；Command+W可分别关闭任务弹窗、设置和主窗口；主窗口关闭后无窗口/应用进程，重新打开可用。原生双击放大、系统窗口还原通过；浏览器双击事件路径通过。未将这次局部验收计为完整产品或硬件功能验收。
