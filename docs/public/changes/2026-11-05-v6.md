## 一、桌面入口与界面模块

- 原生默认页面由经典 `desktop.html` 改为 `cyberme.html`，Vite 增加对应入口；经典工作区保留返回 V6 的入口。
- 新增 `web/src/v6/`：左侧对话，右侧简报、任务、记忆、设置；支持主题、语言、面板宽度及按会话保存未发送输入。
- 聊天与提案按持久请求回执显示准备中、执行中、失败、未知、部分完成和停止；不把模型回复或选项选择当作业务完成。
- 提案和任务详情共用忙碌锁及精确原始任务关联；跨会话跳转按目标历史及异步归属定位。失败/部分完成的逐项发送恢复仍可能需要经典工作区。
- 身份与记忆使用已有文档版本接口，冲突保留输入；模型、连接、权限和能力目录复用既有接口。未实现的技能管理和账户能力保持不可用。

## 二、后端增量与兼容规则

- 草稿增加 `brief` / `warm` 语气，完成输入校验、模型提示词传递、请求账本及指纹绑定。
- 相同请求 ID 不可改变语气；同参数回放返回原结果，旧无语气请求保持历史行为。
- 候选草稿保存语气；应用候选时恢复 `draftTone`，撤销旧审批状态；原请求回查暴露已记录语气。
- Agent 起草能力参数同步增加 `tone`。
- Chat 工作与方向面板公开 DTO 增加可选展示对象 `v6`，不改变业务授权和 canonical 状态。

## 三、共享视觉与静态资产

## 五、验收前关注的失败面

1. 重命名覆盖同名目录或丢失未提交文件；跨机器传输混入凭据、业务库、测试状态。
2. V6 资源能构建但安装版仍旧，误报已升级；静态托管没有 API 却声称可完整运行。
3. 改变语气后复用旧请求、重复生成、候选采用丢语气、历史无语气请求兼容破坏。
4. 将展示步骤对勾、模拟完成回执或创建待办误当作实际业务完成。
5. 推送漏掉尚未提交的 V6 文件，或把前一未推送提交隐含带上而不披露。
