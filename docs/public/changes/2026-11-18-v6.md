# 2026-11-18 CyberMe V6 提交说明

比较基线为本地提交 `27490b1`。该提交已修正回复卡按当前判断与精确请求提供起草入口的规则。本轮在其基础上汇总工作区模块变更。

## 模块变更

| 模块 | 本轮差异 |
| --- | --- |
| 对话与执行 | 每个会话保留一个持续 Agent 会话。普通交办按持久队列执行，明确的补充或更正在工具边界并入当前工作。原请求 ID、时间顺序和部分完成回执用于刷新与重启恢复。准备、模型响应、流式推进和工具等待分别计时。详见[会话](../agent-session.md)、[追加](../chat-input-append.md)和[预算](../chat-time-budgets.md)。 |
| 技能与跟进 | Agent、设置页和输入框读取同一份本机技能目录。显式选择、跨轮续办、当前授权和稳定操作键分别校验。单项跟进绑定来源、原请求、人物与业务版本，按到期证据进入确认或完成，并向原会话投递。详见[技能](../local-skills.md)和[持续跟进](../follow-up.md)。 |
| 洞察与收件箱 | 支持按可信提及元数据配置来源模式。洞察保留证据时间及精确引用，按当前证据和图形复核状态投递。合并洞察流使用一行页脚，支持刷新、恢复忽略和推迟、查看后台失败；摘要保持真实事件顺序，桌面通知可打开对应内容。详见[意图](../intent-handling.md)、[页脚](../insight-footer.md)、[后台可靠性](../insight-reliability.md)和[桌面通知](../desktop-notifications.md)。 |
| 记忆 | 恢复统一全局记忆库，旧项目字段与原会话兼容。Mem0 语义召回使用真实来源回验，失败时回落关键词；撤销与忘记覆盖可追溯派生记录。详见[全局记忆](../global-memory.md)和[资料库](../memory-library.md)。 |
| 模型与连接 | 设置打开时读取模型目录，一个显式当前选项兼容原有普通和深度角色。供应商支持目录读取、编辑与逐模型批量回执，当前模型保持独立连接测试。应用连接支持飞书、微信、Gmail 和 Apple EventKit。Gmail 查信与 OAuth 登录分别授权，GitHub PR 与 Issue 使用受限只读接口。详见[模型设置](../v6-model-settings.md)、[应用连接](../app-connections.md)和[GitHub 与 Apple](../github-apple-read.md)。 |
| 桌面与原型 | MyGO 使用原生窗口拖动，并在签名更新时等待受管服务和子进程排空。当前原型入口展示 V6，旧版目录可追溯。官网独立提供三语静态入口和 Cloudflare Pages 发布说明。详见[窗口](../window-controls.md)、[本机更新](../local-updates.md)、[产品原型](../../../mock/README.md)和[官网](../../../website/README.md)。 |

## 复验

从仓库根目录运行 `npm run build` 和 `npm exec -- vite build --config web/mygo.vite.config.ts`。原生编译在 `native/mygo/` 运行 `go build -trimpath -o ../../.local/mygo-build .`。分层 E2E 的命令与证据边界见[验证](../validation.md)。

受控模型、合成来源、真实 API/SQLite、源码浏览器、官网与历史本机安装结果各有对应证据。GitHub 源码推送与桌面更新、公证及 Cloudflare Pages Direct Upload 为独立步骤。内部 sprint 记录、运行数据、凭据和私有验收产物保存在 Git 忽略路径。
