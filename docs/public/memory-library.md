## 实现前失败清单

- 资料夹只是装饰，点击后不能读取、修改或返回。
- 把 Agent 指令、机器环境或模型推断当作个人事实；用读取时间冒充资料更新时间。
- 只展示摘要，原 Markdown 内容丢失；分类重排意外改写文档。
- 切换资料夹、返回或后台刷新使未保存输入丢失；409 被静默覆盖。
- 人物职级被推成上下级；旧跟踪记录显示为今日新任务。
- 人物接口失败、目录不可读或资料被移除时仍显示缓存为当前有效资料。
- 忘记操作被重复提交，迟到列表又恢复已忘记的条目。
- 窄面板、长中文、英文、深色主题导致溢出；键盘无法打开资料夹或返回。

## 页面与数据边界

采用总览卡与资料夹结构，保持 CyberMe 的主题和双栏布局。个人总览仅显示已有身份信息，不生成传记或推断生活方式。分类是 MEMORY 原文与自动记忆的只读主题索引，不迁移、重命名或改写正文。原始资料夹继续保留 MEMORY 文档原有 `##` 标题。自动记忆、人物档案独立进入；旧 SOUL 文档含身份及行为指令，明确标作「身份与 Agent 设定」，不把其中全部文字当个人事实。

人物档案读取已配置的人员资料目录，保留原文、角色、关系与原资料日期。跟踪记录与原档案分开，展示事件时间和来源；历史记录不成为当前任务或新提醒。不写回原人员 Wiki，不新增分析运行。

文档编辑继续沿用 version 保存、冲突保留、手动核对及草稿恢复。总览不持久缓存人物原文或完整个人文档；读取失败显示可重试状态。
