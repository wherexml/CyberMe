# 提醒与报错展示

2026-10-24，遵循根目录 design.md。范围为桌面聊天恢复状态、消息错误、共享错误提示；不改变请求状态机、重试权限和 invalid_evidence。

## 实现前失败面

- 未确认、部分完成、失败不能被隐藏或显示成功；部分完成不可重试，检查结果只读取原请求。
- 恢复入口不再占用整行灰色底板；多条记录可折叠查看，控件可键盘访问。
- 聊天错误先给简短结论，原始诊断按需展开；正常等待仍只有三点。
- 深色、浅色和窄窗下可读、不溢出，不影响输入框、草稿和阅读位置。
- 会话切换时清理上一会话恢复入口；迟到返回不能把提示插入其他会话。
- 安装包保留既有功能和业务数据，实际原生验证与公开浏览器 fixture 分开记录。

## 展示约定

未确认记录以单行折叠入口展示，展开后按记录查看详情；切换会话立即移除上一会话入口。聊天失败和部分完成状态采用无底板正文，首先展示简短结论，诊断文本在“查看详情”中展开。共享错误提示与恢复操作不使用整行灰底卡片，按钮采用文字样式并保留键盘焦点。

正常等待保持三点，未知结果只读检查，部分完成没有重试入口；不改变后端与既有幂等约束。
