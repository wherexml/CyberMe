# 本机更新等待与退出排空

2026-11-13。适用现有 CyberMe standalone 本机签名更新通道。

## 失败面

持续同步子进程会使原先的“存在任意子进程即忙碌”判断反复返回等待；实际 Agent 可能早已结束。修复必须继续拒绝真正运行中的 Agent、未知包内进程、外来端口、非法签名、版本/数据代际冲突和并发事务；未退出的子进程不能被强杀或被忽略后替换包。

## 行为

准备阶段以真实运行记录检查 Agent，并校验服务和更新包。原生应用正常退出后，helper 向已核实服务发送 SIGTERM，保守跟踪现存及退出期间的子进程，等待它们退出和端口释放。排空默认最多十秒；超时返回 `runtime_exit_timeout`，保留旧包。对子进程只等待，不强杀；进程标题变化不能被误当作已退出。

原签名、身份、代际、事务锁、备份、启动健康与回滚流程保留。没有新增调度器或 UI 文案。
