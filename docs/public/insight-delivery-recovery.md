3. 首次启动及记录变化只安排有界后台工作，不得并行重复生成、超出队列/日预算或反复重试终态。
4. `urgent_digest` / `digest` 下普通洞察被静默消费；应进入既有持久摘要，紧急请求继续遵循现有档位。
5. `information` / `delegation` 是可阅读的新事实，不是本人任务；可按设置提醒，不得创建任务、起草、执行或外发。
6. 历史、过期、证据漂移、撤权、忽略、已结束、侧会话及已归档主会话不得恢复投递；切换版本不能补推历史积压。
7. 免打扰期间摘要等待；重启与重复同步不得重复，三小时/三行上限保留；静默单事项继续静默。
8. 摘要应称洞察或更新，不把信息更新写成“等你处理”，也不把剩余洞察指向不存在的决策分页。
9. 摘要中的洞察被更新、来源变化或改成静默时，旧行须撤回，不能复用旧版本文案；摘要追问同样复核精确来源，不能加载已撤回内容。
10. 源码、隔离 HTTP/浏览器、真实模型、签名包和安装版分别记录；截图及 URL 作为可复验产物，私有正文不进入 Git 或日志。
