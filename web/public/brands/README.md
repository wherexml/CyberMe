# Product marks

Product SVG marks vendored from https://github.com/homarr-labs/dashboard-icons/tree/main/svg on 2026-10-03; upstream filenames: gmail, slack, google-calendar, microsoft-teams, lark, wechat, whatsapp, telegram. Feishu uses the Lark product mark. Trademarks remain with their respective owners. Assets are served locally, without third-party image requests.

Added 2026-10-26 from the same upstream (https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/): figma, zoom, salesforce, notion, google-drive, dropbox, github, linear, zendesk, apple. The Apple mark is used for Apple Mail, Calendar, Notes and Reminders, matching the V6 reference (which resolved all of them to the apple.com favicon).
Not available upstream, so taken from the exact source the V6 reference used (`https://www.google.com/s2/favicons?domain=<domain>&sz=64`): outlook.jpg (outlook.live.com), hubspot.png (hubspot.com), mixpanel.png (mixpanel.com).
